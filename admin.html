Naija Vanguard admin panel

Tune the game, design enemy types and custom waves. Changes are saved in this browser (localStorage) and apply the next time you start a mission. Use export/import to copy a config between machines — or paste exported values into DEFAULT_CONFIG in game.js to change the defaults for everyone who plays your hosted copy.

Core tuning

Weapons (JSON array)

Each weapon: { "name", "cooldown" (frames between shots), "damage", "dmgPerWave", "bulletSpeed", "pellets", "spread" (radians), "infinite" (true = no ammo needed) or "startAmmo" + "maxAmmo", "color" }. Weapon 1 is the default rifle and should stay infinite.

Difficulties (JSON array)

Each: { "name", "enemyHpMult", "enemySpeedMult", "enemyCountMult", "lives" }. The menu dropdown lists them in order.

Maps / levels (JSON array)

Each: { "name", "tint" (hex background), "walls": [{ "x", "y", "w", "h" }] }. The player advances to the next map every "waves per level" waves.

Enemy types (JSON array)

Each type: { "name", "color" (hex), "hpMult", "speedMult", "size" (px radius) }. Raiders and brutes included by default — edit freely, add more.

Custom waves (JSON array, optional)

Each entry overrides one wave: { "count": 12, "type": 0, "hpMult": 1.5, "speedMult": 1.2 }. Waves beyond your list use the normal generator. Keep it [] to disable.
